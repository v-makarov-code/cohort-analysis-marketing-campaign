# Когортный анализ и анализ пользователей у которых был сбой


## Обзор проекта, цель и задачи

Произошло два значительных события. 
Первое и маркетологи провели крупную рекламную кампанию, и в приложение пришло много новых пользовател. ! Второе — в один из дней у нас резко упала аудитор.и
**Цель:** Проанализировать поведения пользователей, привлеченных рекламной кампанией. Выяснить, какие пользователи не смогли воспользоваться лентой во время сбоя.
